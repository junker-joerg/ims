# IMS Python-Portierung

Dieses Paket enthaelt die schrittweise Python-Portierung des historischen
IMS/ESS-Modells. Fachliche Zuordnungen, Validierungsgrenzen und offene
Migrationspunkte sind im Repository unter `docs/migration/` dokumentiert.

Die Paketbeschreibung ist bewusst lokal abgelegt, damit isolierte Builds und
Editable-Installationen nicht auf Dateien ausserhalb von `python_port/`
zugreifen muessen.
